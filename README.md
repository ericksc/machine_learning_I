# Aula de Aprendizaje Automático I

Sitio estático en español para el Técnico en Gestión de Datos para el Análisis y Visualización.

## Uso

Abra `dist/index.html` en un navegador. No requiere instalación ni conexión para leer los contenidos, realizar los laboratorios o responder las autoevaluaciones. Los cuadernos requieren un entorno Python independiente.

El sitio contiene seis accesos semanales, cuatro secciones por semana y 36 subsecciones temáticas detalladas en Explora. Cada subsección tiene objetivo, explicación, puntos clave, ejemplo aplicado y pregunta con respuesta orientativa. El índice numerado permite navegar directamente; cada tema tiene un enlace propio, por ejemplo `#semana-2/explora/4`.

Cada una de las 36 subsecciones incluye una tabla y una figura contextual: matrices, curvas, barras, diagramas de redes, flujos o dendrogramas. Los ejercicios, prácticas y materiales también incluyen apoyos visuales. Las figuras son SVG locales con descripción accesible y pie explicativo; las tablas tienen títulos y encabezados. Los ejemplos numéricos ilustrativos se identifican expresamente. Las tablas y figuras anchas permiten desplazamiento horizontal en pantallas pequeñas.

También incluye seis laboratorios interactivos, dieciocho preguntas con retroalimentación y una selección de los materiales originales. Las respuestas permanecen en memoria durante la sesión de la página; no hay cuentas, calificaciones oficiales ni almacenamiento en un servidor.

## Edición

- `dist/content.js`: contenido docente, preguntas y recursos.
- `dist/lessons.js`: 36 subsecciones detalladas, seis por semana.
- `dist/visuals.js`: tablas, diagramas y gráficos educativos por subsección.
- `dist/app.js`: navegación, laboratorios y autoevaluación.
- `dist/styles.css`: diseño adaptable y accesibilidad.
- `dist/materiales/`: copias de los recursos seleccionados; los cuadernos distribuidos no contienen salidas de ejecución.

Los laboratorios usan ejemplos didácticos pequeños. Los fragmentos Python son referencias para los cuadernos, no un ejecutor Python integrado.
